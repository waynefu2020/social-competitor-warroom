# 🌍 海外竞品调研 & 全品类自适应作战手册（Overseas & Cross-Category Playbook）

本手册沉淀自多个真实出海与全品类竞品调研实战（涵盖 **AI SaaS / App**：`Manus`、`Granola`、`Wispr Flow`、`Genspark`、`Gamma`、`TurboAI`、`StudleyAI`、`Coconote`；**美妆个护 D2C**：`Flower Knows 花知晓`；**智能硬件**：`Plaud` 等）。当用户的调研对象涉及**海外市场（YouTube / TikTok / Instagram / Reddit / App Store）**或**非硬件品类（SaaS / App / 美妆消费品 / 教育 / 跨境电商）**时，严格遵循本手册执行。

## 二、海外社媒「赞助指纹深挖法（Sponsor Fingerprint）」

在海外平台（尤其是 YouTube 与 TikTok），如果只搜品牌词（如 `"Granola"` 或 `"Gamma"`），会搜出成千上万条“燕麦食谱”或“物理射线”噪音。**要精准抓出竞品真正花钱投的红人商单，必须直接搜简介里的「赞助指纹」：**

### 1. 四类高命中赞助指纹 Query 模板（用于 YouTube / TikTok / Google 搜索）
1. **专属追踪短链指纹（最准，100% 为官方合作）**：
   - `"go.<brand>.ai"`、`"<brand>.ai/?via"`、`"ref.<brand>.ai"`、`"<brand>.im/redeem"`、`"<brand>.yt.link"`、`"try.<brand>.app"`、`"*.sjv.io"`（Impact 联盟）
2. **明确赞助披露指纹**：
   - `"sponsored by <brand>"`、`"thanks to <brand> for sponsoring"`、`"brought to you by <brand>"`、`"partnered with <brand>"`、`"#<brand>partner"`
3. **权益钩子指纹（结合品牌词）**：
   - `"<brand>" "first month free"`、`"<brand>" "free credits"`、`"<brand>" "discount code"`、`"<brand>" "link in description"`
4. **多语种赞助标签（查日/韩/德/西/法本地化投放）**：
   - 日语：`#PR`、`提供`、`タイアップ`
   - 韩语：`#광고`、`#협찬`、`유료광고`
   - 德语/西语：`#werbung`、`#anzeige`、`#publi`

### 2. 五级商业合作定性分类（严禁混在一起算中位数！）
每条抓取到的海外/国内内容，必须按以下优先级定性归类（**做播放量/互动中位数统计时，只在同一层级内对比**）：

| 层级 | 判定规则 | 植入形态细分 & 战略含义 |
| :--- | :--- | :--- |
| **L1 · 明确品牌付费商单 (`Paid Sponsorship`)** | 含 `sponsored by`、`paid partnership`、YouTube 章节含 `Sponsor`、小红书蒲公英 `cooperate_binds`、抖音星图 `is_star=true` | 细分为：<br>① **30-60s 口播植入 (Mid-roll Integration)**：常投向非本品类的泛高净值大号（如商业播客、个人理财、家居改造、泛娱乐千万级大V），负责破圈拿几十万~百万级大曝光；<br>② **专场深度实测 (Dedicated Review/Challenge)**：要求博主拿一个完整真实项目从头做到尾（如 Manus 一镜到底做游戏/建站）。 |
| **L2 · 专属短链/定制码合作 (`Custom Link / Code`)** | 无显式 `#ad`，但简介首行挂有博主名字的定制短链（如 `go.granola.ai/joshua`）或专属兑换码（`CODE10`） | 品牌直接建联的绩效/混合合作，用于直接追踪 ROI 转化。 |
| **L3 · PR 礼盒寄样 (`Gifted / PR Haul`)** | 含 `PR package`、`PR haul`、`gifted`、`sent me`、`thank you @brand` | 美妆/时尚/潮玩出海（如花知晓）的核心槓杆，低成本激发高颜值开箱自传播。 |
| **L4 · 联盟分佣长尾 (`Affiliate / Shop`)** | 挂 TikTok Shop 小黄车、`amzn.to` 亚马逊联盟、`sjv.io`、YesStyle 零售码，或放在 YouTube 简介底栏 `My Top Tools / Favorite Tools` 列表里 | **注意剔除底栏常驻工具单对商单统计的污染**！联盟号通常数量多但单条播放中位数极低（如纳米号 SEO 教程仅几十~几百播放）。 |
| **L5 · 纯自然内容与真实吐槽 (`Organic / VOC`)** | 排除以上所有商业信号，且可匹配 `not sponsored / unsponsored` 声明 | 反映产品真实的自然口碑、野生 CP 玩法与真实退货槽点。 |

### 3. 竞品打法画像自动判定（4 种原型）
- **买量重投型**：`品牌主导内容（L1+L2）播放中位数 ÷ 自然内容播放中位数 ≥ 5`。声量靠集中砸中头部大 V（如 Plaud 在 TikTok 品牌商单中位 21.4 万 vs 自然 1,400；Wispr Flow 投 Unbox Therapy）。
- **自来水裂变型**：`自然内容占比 ≥ 60%` 且自然播放中位数 ≥ 商单。产品自带极强社交货币或开箱颜值（如 Flower Knows 花知晓）。
- **联盟铺量型**：`L4 联盟内容占商业内容 ≥ 50%`。靠高分佣发动海量纳米小号铺关键词 SEO 与带货挂车。
- **跨界泛投破圈型**：`80% 以上高播放商单来自非本垂类的泛生活/商业/理财/娱乐频道 30-60s 口播植入`（如 Gamma 5 投音乐发明、Kpop MV 剪辑、独居装修 Vlog；Granola 连续复投理财与商业播客 10+ 期）。

## 三、每个竞品必拆的「🟢 爆款内容 vs 🔴 效果差的内容」对照法

在输出竞品档案（第 04 章）与渠道打法（第 02 章）时，**绝不能只笼统写“投了 YouTube/TikTok 博主”**，必须像下面这样对比拆出竞品交过学费的真实规律：

- **🟢 爆款内容（What Worked · 几十万~百万级播放）**：
  - *示例 1（SaaS/App - Manus）*：“不再测零散功能点，直接丢给 AI 一个真实完整项目从零做到上线”的挑战型专场（如 Shark Numbers 187.9 万播放），以及跨语区（韩语 UhBee World 13.3 万、日语 PIVOT 11.6 万、西语 Ángel Molina 18.2 万）百万大号同步轰炸。
  - *示例 2（效率工具 - Granola / Gamma）*：跳出拥挤的“AI 工具测评号”，在商业访谈播客、个人理财（I Will Teach You To Be Rich 32.9 万）、家居改造 Vlog、建筑设计号中做 **30-60 秒痛点口播植入**。
  - *示例 3（新功能带老品 - Wispr Flow）*：趁上线新功能（Notetaker），用“**买一送一式权益钩子**（送 1 个月 Pro = 无限会议纪要 + 无限语音输入）”在 AI 编程与极客工作台开箱视频中收割高净值人群。
- **🔴 效果差的内容（What Flopped · 几十~几百播放，我方切勿踩坑）**：
  - *示例 1*：小号批量拆分的“如何安装 XX / 如何在 XX 里加饼图 / 如何导出笔记”机械式功能说明书 SEO 视频（普遍仅 10~180 播放）。
  - *示例 2*：纯“如何免费白嫖积分/邀请码”的羊毛党教程（不仅播放低，且吸引来的全是不付费羊毛党）。
  - *示例 3*：找粉丝少、商业化弱的“纯身份型素人口播”（单价是泛人群的 3 倍，播放反而垫底；**实战证明：找科技/效率/商业场景型大号来演目标人群痛点，远比直接找素描身份小号跑量！**）。

## 四、实战防坑指南（Pitfalls · 写报告前必查）

1. **同名噪音过滤 (`noise_regex`)**：
   - 搜 `Granola` 必过滤 `recipe|bake|baking|yogurt|oats|breakfast|cereal|granola bar|homemade`；
   - 搜 `Plaud` 必过滤波多黎各政治人物新闻 `Félix Plaud` 与西语动词 `aplaudir`；
   - 搜任何日常英文单词品牌，必须先抽查前 20 条结果，写好 `noise_regex` 再全量统计。
2. **官方号与假冒店过滤 (`official_regex`)**：
   - 用户名含品牌名的账号（如 `@flowerknows.us`, `plaud_vn`, `@manusai`, `@meetgranola` 以及 Shopee 搬运店）一律从红人样本中剔除，否则会把官方自播算成 KOL 投放。
3. **竞品反向赞助的对比视频（`"X vs Brand"` 陷阱）**：
   - YouTube 上标题为 `"Flowtica vs Plaud"` 或 `"X vs Granola"` 的视频，往往是竞品 X 花钱赞助来踩该品牌的！必须看简介里的折扣码和链接到底归属谁，切勿算进被踩品牌的投放里。
4. **集中度警告（Concentration Warning `⚠`）**：
   - 如果某个赛道/语种的高播放 10 万+ 爆款里，**单个账号贡献了 >30% 的条数**（例如某包月号一人发了 18 条里的 13 条），或者**单一国家市场（如日本）占了 >60%**，必须在报告中明确标出 `⚠ 高度集中`，并给出剔除该单一账号后的真实中位数，严禁以偏概全。
5. **博主赛道分类严禁用简介关键词正则一刀切**：
   - 海外科技/生活博主简介里常写 `"Business enquiries: xxx@gmail.com"` 或 `"Digital Marketing"`，如果用正则匹配 `business` 会把大量科技娱乐号误判为“创业商业号”。必须结合频道实际内容分类。
