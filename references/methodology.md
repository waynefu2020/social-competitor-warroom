# 口径与方法

## 0. 选竞品

用户点名了就用用户的。只给了品类时，从三个方向各挑一个，凑够 3 个就够，多了分析不深：

| 方向 | 怎么找 | 适合谁 |
|---|---|---|
| **体量相近、阶段相近** | Google Trends 看品牌词什么时候开始起量；在 TikTok/小红书搜品牌，看最早的红人内容出现在什么时候。挑和我方起步时间、规模差不多的 | 品牌还小、预算有限的，最有参考价值 |
| **同品类里内容最能打的** | 各平台搜品类词，看每个候选品牌播放最高的前几条内容，选整体表现最好的 | 想学怎么拍、找爆款模板时 |
| **品类头部** | 行业榜单、电商类目排名、媒体报道 | 我方已有一定知名度时；起步期只作天花板参考，它的预算没法照搬 |

Google Trends 还能对比几个品牌在不同国家的热度，看出各自主攻哪些市场。选完写进 brief 的 `decision_question`，说明为什么选它。


## 1. 内容分类（每条内容只归一类，按优先级判定）

| 类型 | 判定信号 | 含义 |
|---|---|---|
| **付费合作 paid** | 文案含 #ad / #sponsored / paid partnership / sponsored by / #werbung / #anzeige / #광고 / #adv；IG `is_paid_partnership` 或 `sponsor_tags`；TikTok `is_ads`；小红书蒲公英订单；抖音星图商单 | 品牌花钱买的内容 |
| **寄样 gifted** | PR package / PR haul / gifted / #pr / sent me / thank you @品牌 / 협찬 / 提供 / いただきました | 品牌送了产品，未必付费 |
| **联盟带货 affiliate** | TikTok Shop 商品锚点；抖音小黄车；折扣码（code XXX、% off）；零售或电商链接（Amazon、YesStyle、Shopee、Ulta…）；link in bio | 博主靠分佣变现，品牌按效果付费 |
| **品牌合作（未注明）collab** | 只有平台商业披露标记（TikTok `branded_content_type` 非 0/7/13），文案没写明是付费还是寄样 | 有商业关系，但性质不明 |
| **自然内容 organic** | 以上都没有 | 用户自发内容（"自来水"），含没披露的软广 |

判定顺序：付费文案/标记 → 寄样文案 → 联盟信号 → 平台披露 → 自然。文案优先于平台字段，因为平台字段只说明"有商业关系"，说不清是哪种。

**品牌主导内容**（用于打法画像）= 付费 + 品牌合作 + 寄样 + 带"官网专属折扣码"的联盟内容。它反映品牌主动发起的合作；TikTok Shop / 亚马逊 / 零售链接这类分佣长尾不算。

## 2. 采集设计

- **时间窗**：默认 90 天。小红书默认 30 天（内容生命周期短）。
- **关键词**：品牌名的所有写法 + 品牌名 × {review, unboxing, haul, vs, tutorial} + 主力产品/系列名。不要只搜品牌名，测评和对比类内容常只写产品名。
- **话题**：品牌主话题 + 合作专用话题（如 #plaudpartner、#品牌partner）+ 活动/快闪话题。合作话题是付费投放最干净的信号，优先找出来：先跑一轮，统计高频话题，再补搜。
- **剔除**：官方号与区域官方号、仿冒/转售号（用户名含品牌名的一律剔除）、同名噪音、竞品赞助的"X vs 品牌"对比视频。

## 3. 核心 KPI

| KPI | 定义 | 解读 |
|---|---|---|
| 自然内容占比 | organic / 全部 | 越高越依赖用户自传播 |
| 付费 / 寄样 / 联盟占比 | 各类 / 全部 | 投放结构 |
| 品牌主导 vs 自然播放倍数 | 品牌主导内容播放中位数 ÷ 自然内容播放中位数（TikTok） | ≥5：钱买来的声量远高于自然声量 |
| 商业博主粉丝中位数 | 非自然内容博主的粉丝中位数 | 投放偏头部还是偏素人 |
| 人均合作内容数 | 商业内容条数 ÷ 商业博主数 | ≈1 说明单次合作，>1.5 说明长期/系列合作 |
| 官网社交流量占比 | Similarweb socialOrganic + socialPaid | 社媒对官网的直接导流力度 |

中位数而不是平均数：头部爆款会把平均数拉到失真。

**博主量级效果**：按粉丝量级（<1万、1–10万、10–50万、50–100万、100万+）看商业内容的播放中位数和“播放÷粉丝”。前者回答“哪档能扛量”，后者在没有报价时近似“哪档最划算”。每档少于 5 条不参与比较。

## 4. 打法画像判定（analyze.py 自动给出，写结论时可修正并说明理由）

按顺序判定：

1. **买量型**：品牌主导 vs 自然播放倍数 ≥ 5。钱集中投在少数中头部博主，声量靠买。（例：Plaud）
2. **自来水型**：自然内容占比 ≥ 60% 且自然内容播放中位数 ≥ 品牌主导内容。产品本身有分享欲，品牌主要做寄样和低门槛联盟。（例：花知晓）
3. **联盟铺量型**：联盟内容占商业内容 ≥ 50%。靠分佣让大量中小博主带货。
4. **混合型**：以上都不明显。

## 5. 置信度

- 搜索是抽样，规模类数字（"投了多少博主"）一律写"可观测到的下限"。
- 比例和中位数比绝对数可靠，结论优先用比例。
- 每平台样本 < 30 条的指标只作参考，在报告里注明样本量。
- 公开报道的营收/估值数字口径常不一致，全部列出并标来源。

## 6. 比较的规则

- **同类才比**：博主类型只在同一合作类型内比；我方数据只在同一条路线（铺量 / 精品）内比。见 `audience-research.md`。
- **报集中度**：单个账号占一组 >30%，或单个品牌/市场占 >60%，要写出来，并给出去掉头部之后的数字。
- **补抓要全量**：粉丝数、简介要么全部补，要么都不补，不能只补热门帖。
- **博主类型人工标**：用 `labels.py`，标注表随报告交付。
- **没价格不谈效率**：竞品只比播放、互动和互动÷粉丝。
