① 暖纸社论杂志风（默认推荐）

editorial

灵感源自 Kinfolk / Monocle 杂志。米白暖纸底 + 炭黑墨色 + 爱马仕橙 + 橄榄绿破局卡，配思源宋体大标题与衬线巨型数字。

最适合：给老板/合伙人/投资人深度阅读、品牌战略复盘（与内置 Editorial 经典暖白研报模板完全同款）

② 暗黑流光便当盒风

bento-dark

灵感源自 Dribbble 科技榜首 Linear / Raycast。深邃曜石黑底 + 1px 微光玻璃边框 + 靛蓝/翠绿霓虹高亮，非对称便当盒模块化卡片。

最适合：AI 产品、智能硬件、SaaS 工具、极客产品路演大屏投屏

③ 麦肯锡高管作战看板

mckinsey

灵感源自 Pitch / Stripe 商业尽调看板。纯净白灰底 + 深海蓝 + 皇家蓝，严格遵循 Action Title 结论先行与高信噪比表格。

最适合：正式商业立项会、投融资尽调、B2B 企业服务、大厂述职汇报

④ 瑞士国际主义网格风

swiss

灵感源自 Readymag / Pentagram 先锋设计。2px 建筑感实黑分割线 + 0圆角硬边阴影 + 瑞士高饱和红与巨型几何数字。

最适合：潮流硬件、设计驱动型品牌、超级个体/独立开发者、高辨识度展示

⑤ 小红书原生手账拆解风

xhs-craft

灵感源自小红书万赞干货笔记。米黄方格纸纹理 + 荧光笔半截涂抹高亮 + 和纸胶带与便利贴卡片，亲和力拉满。

最适合：社媒运营团队内部脑暴、美妆/母婴/生活方式品类、直接截图发小红书干货贴
